- 🌱 Deep-diving into **Windows internals**: minifilter drivers, WFP auditing, kernel callbacks, ETW instrumentation

- 🛠 Tech stack: `C/C++ (Win32/WDK)` · `Python (FastAPI/DuckDB)` · `JavaScript`

- 🎯 Goal: make EDR internals **learnable** — every sensor, rule and response action is inspectable
